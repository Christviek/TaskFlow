About the Application

TaskFlow supports account registration and login, task creation and management, task filtering, dashboard statistics and persistent data storage.

The application uses HTML, CSS and JavaScript for the front end, Node.js and Express for the server, and SQLite for data storage.

The evidence documents explain the project's requirements and planning, as well as the development process and lessons learned.
